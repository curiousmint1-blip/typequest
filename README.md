# ⌨️ TypeQuest — Typing Practice & Games

A complete typing-tutor website in a single file — works fully offline! Just open `index.html` in any browser.

## ✨ Features

| Feature | Description |
|---|---|
| 📝 **Practice** | Time (15/30/60/120s), Words (10/25/50/100) & Quote modes — Easy/Medium/Hard difficulty |
| 📚 **18 Lessons** | Step-by-step from home row (F/J) to numbers & punctuation — ⭐ stars and unlock system |
| 👆 **Finger Guide** | See exactly which finger presses which key — color-coded hand diagram + interactive keyboard |
| 🎮 **2 Games** | 🌧️ Word Rain & 🚀 Space Defender — levels, combos, lives, bosses |
| 🔊 **Sound Effects** | Mechanical / Typewriter / Soft key sounds, errors, combos, lasers & explosions (Web Audio API) |
| 🎨 **6 Themes** | Synthwave, Dracula, Matrix, Nord, Sunset & Light |
| 📊 **Smart Stats** | WPM history chart, per-key accuracy heatmap, weak-key practice |
| 🏆 **10 Achievements** | Unlock badges and break your records |
| 💾 **Progress Saving** | Everything is stored in localStorage |

## 🚀 Getting Started

- Double-click `index.html` to open it in any browser — no internet needed.
- New to touch typing? Start with **Lessons → Lesson 1 (F & J)**.
- While typing, the on-screen keyboard glows to show the next key and which finger to use.
- Use an **English (US)** keyboard layout for practice.

## ⌨️ Shortcuts

- `Tab` — restart test
- `Esc` — restart (practice) / pause (games)
- `Backspace` — fix mistakes

## 🔧 Tech

One self-contained HTML file (no external CSS/JS/fonts). Sound is synthesized with the Web Audio API, particles & games run on Canvas 2D, and all progress lives in localStorage.
